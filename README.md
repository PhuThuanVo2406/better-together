# Better Together

Website for **Better Together**, a student conference on belonging and student connection hosted by Phi Theta Kappa, Omega Sigma Chapter (Houston City College). It is the action component of the chapter's 2026–2027 Honors in Action project.

## What's here

- `index.html`: the whole site in one file (HTML, CSS and JavaScript). Open it in a browser to view it.

The background is a WebGL fluid simulation (based on Pavel Dobryakov's MIT-licensed WebGL Fluid Simulation). Fonts load from Google Fonts and smooth scrolling from Lenis on unpkg.
